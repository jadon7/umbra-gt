# UMBRA GT 宣传片

- `umbra-gt-promo.mp4`：成片，2560×1440、60 帧/秒恒定、H.264 High（yuv420p、BT.709）+ AAC 320 kbps / 48 kHz 立体声，55 秒，素材录于 0.14.0
- `poster.jpg`：封面帧（2560×1440）
- `xhs-cover-a.png`、`xhs-cover-b.png`：小红书封面（竖版 3:4，1086×1448），用 Codex 的出图功能按真实游戏截图重画的，不是游戏原始画面；A 的标题是「AI 做了个赛车游戏」，B 是「浏览器里的街头赛车」

画面里没有任何网址、域名、二维码或引流的话（要发到平台上，有网址会被限流），文件的元数据里也只写了标题。片尾只有游戏名和一句标语，底部一行小字是车辆模型的署名（CC BY 4.0 素材，公开发布要署名；不想要的话把 `cards.ts` 里的 `CREDIT` 改成 `false`）。

## 规格和做法

- **渲染**：无头 Chrome 打开游戏（`q=high` 最高画质档、`px=0` 不限渲染分辨率），页面 2560×1440、像素倍率 2，也就是每帧按 **5120×2880** 渲染；截屏是 **PNG（无损）**，ffmpeg 用 lanczos 缩到 2560×1440。在 M3 Max 上机器空闲时每帧约 1.3–1.5 秒（渲染 0.14 秒，其余是浏览器编 PNG）；内存吃紧（开始用交换区）时会慢到每帧 3–7 秒。
- **逐帧推进**：停掉页面自己的动画循环，每帧让游戏正好走 1/60 秒再截屏（`src/main.ts` 里的录制入口 `__app.rec`），所以 60 帧里每一帧都是真实渲染的不同画面，没有补帧和重复帧。
- **素材**：H.264 4:4:4、CRF 7（接近无损），剪辑时只转一次 4:2:0。
- **成片编码**：x264 preset slow、CRF 15、High@5.1，`+faststart`。
- **配乐**：全部用代码合成（120 拍/分钟，D 小调），没有任何录音素材；剪辑时响度归一到 −14 LUFS、真峰值不超过 −1 dBTP。
- 自己加的镜头运动（推近、横移、车库环绕）都是匀速的线性插值；游戏自带的追尾、电影镜头、赛前镜头照游戏自己的来。转场是踩在拍子上的硬切或线性的短叠化。

## 重新生成

开发服务器要跑着（`npm run dev`；5173 端口被别的项目占着时，用 `.claude/launch.json` 里的 `promo` 配置，它在 5183 端口，`GAME_URL` 跟着改），中间文件放在项目外面（这个目录被网盘同步，素材又大，约 2 GB）：

```bash
export GAME_URL=http://localhost:5173/      # 开发服务器的地址
export PROMO_WORK=/tmp/umbra-promo-work     # 中间文件放哪（不写就是系统临时目录下的 umbra-gt-promo-work）
node promo/record.ts     # 录全部镜头 → $PROMO_WORK/clips/（约 4600 帧，机器空闲时约 2 小时）
node promo/cards.ts      # 标题字幕、结尾卡 → $PROMO_WORK/title.png、end.png
node promo/music.ts      # 配乐 → $PROMO_WORK/music.wav
node promo/edit.ts       # 剪辑 → promo/umbra-gt-promo.mp4、promo/poster.jpg（--out=路径 可以先写到别处）
```

做完把 `$PROMO_WORK` 删掉。

- **只开一个录制进程**。试过两个进程并行：每个浏览器按 5120×2880 渲染要占好几 GB 显存（和内存是同一块），两个一起开会把系统压到大量使用交换区，磁盘剩余空间被交换文件吃掉好几 GB，而且两个进程都慢到原来的二三倍，并不更快。
- 录制脚本每一步都有超时（页面卡住时一帧 60 秒没返回就报错），出错的镜头会换一个新浏览器重录一次。`PROMO_SCALE=1.5` 可以把渲染倍率降到 3840×2160（机器跑不动 2 倍时用）。

- `shots.ts`：每个镜头的场景、车怎么开、镜头怎么摆（代码在游戏页面里执行，工具在 `lib.ts`）；`keep` 是这个镜头真正存下来的那一段帧。大部分镜头是游戏自己的表演式自动驾驶在开（漂移、氮气都是它决定的），电影镜头用 `P.cineKinds` 指定机位。
- `node promo/record.ts --scout 镜头名`（加 `--every=30` 每 30 帧存一张）只存几张 1 倍像素的静帧到 `$PROMO_WORK/scout/`，调机位用，几十秒一个镜头。
- `record.ts`：录制；`browser.ts`：起无头 Chrome、连 DevTools 协议、截屏。
- `edit.ts`：时间线（每段从哪个镜头的第几帧开始、用多长、和下一段叠化多少帧）。一拍 = 0.5 秒 = 30 帧，剪辑点都在拍子上。
- `music.ts`：配乐；`SECTIONS` 里是各段落从第几拍开始，和 `edit.ts` 的时间线对齐。
- `cards.ts`：标题字幕（透明底，叠在起步的镜头上）和结尾卡。
